# TruckLoad Hub (TL Hub) 🚛📦

TruckLoad Hub is a modern logistics and freight-matching platform designed to bridge the gap between truck drivers and shippers (loaders). The application simplifies the supply chain by allowing drivers to find optimal routes/loads and enabling loaders to track and secure reliable transportation for their shipments.

## 🚀 Key Features

* **Dual-User Ecosystem:** Dedicated onboarding pipelines and dashboards for both **Drivers** and **Loaders**.
* **Profile Verification:** Secure verification workflow ensuring trust and compliance across the platform.
* **Smart Freight Matching:** Interactive search tools for drivers to look up available cargo and loaders to find empty trucks.
* **Deal Negotiation System:** Direct proposal flow allowing users to send, receive, and accept contract pricing.
* **Trip Lifecycle Management:** End-to-end status tracking from initial matching to successful delivery completion.

## 🗺️ How It Works

1. **Register:** Create a specialized Driver or Loader account.
2. **Verify:** Submit documentation to complete your profile and receive a verified badge.
3. **Find a Match:** Shippers post loads; drivers search based on capacity and route.
4. **Make a Deal:** Submit deal requests and locks in pricing terms mutually.
5. **Complete Trip:** Execute the haul and mark the shipment as successfully delivered.

## 🛠️ Technology Stack

* **Frontend:** React.js 
* **Backend:**  Python (FastAPI)
* **Database:** PostgreSQL / MongoDB
* **Authentication:**  Auth with Role-Based Access Control (RBAC)

## 📦 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd truckload-hub
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the root directory and add your configurations (Database URIs, API keys, etc.).

4. **Run the development server:**
   ```bash
   npm run dev
   ```
